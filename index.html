  • Provider adapters

    4 adapters · stream + json

  • Fallback + backoff

    Token usage per request priced in USD from versioned prices.json (per-model in/out rates). /costs endpoint returns session totals. Matches manual token math within ±2% on the fixture set.

FAQ

Why not just use LiteLLM?

LiteLLM is proxy infrastructure — a server you deploy to route traffic between providers. This kit is app-level starter code: chat UI, eval harness, and a cost meter wired into the request path, shipped as source you own and edit. The README states this comparison honestly; pick the proxy if routing is your product.
